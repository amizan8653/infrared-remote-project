from:
https://github.com/AnaviTechnology/anavi-docs/blob/main/anavi-infrared-phat/anavi-infrared-phat.md#infrared-and-lirc


`sudo apt install -y lirc`

add the following 2 lines to /boot/firmware/config.txt with `sudo nano /boot/firmware/config.txt`

edit `/etc/lirc/lirc_options.conf` with `sudo nano /etc/lirc/lirc_options.conf` to have the following lines: 

```
driver          = default
device          = auto
```

the above is different from what the github says: github says instead of putting auto, to use the transmitter or receiver. 
but... at least after I've already defined the remote, auto works perfectly.
maybe I would need to manually set it to the receiver if reading in a new remote.


```
dtoverlay=gpio-ir,gpio_pin=18
dtoverlay=gpio-ir-tx,gpio_pin=17
```

reboot
`sudo reboot`

You've already done the work to setup the remotes data.

back up the original: 
`sudo mv /etc/lirc/lircd.conf /etc/lirc/lircd-backup.conf`

copy over the one you configured:
`sudo cp ./combined.lircd.conf.txt /etc/lirc/lircd.conf`


kick off the service.
`sudo systemctl restart lircd`

note: adding a new remote: 
basically follow this guide to make sure you have the lirc library setup: 
https://github.com/AnaviTechnology/anavi-docs/blob/main/anavi-infrared-phat/anavi-infrared-phat.md#setting-up-lirc

the go ahead and setup the new remote with: 
https://github.com/AnaviTechnology/anavi-docs/blob/main/anavi-infrared-phat/anavi-infrared-phat.md#using-ir-receiver
```
# Stop LIRC systemd service
sudo systemctl stop lircd

# List all available names for buttons supported by LIRC:
irrecord --list-namespace

# Type in the following command to create new LIRC control configuration file and follow the on screen instructions to scan a remote control:
irrecord -d /dev/lirc1 ~./temp-lircd.conf

Let's say during the instructions, when it asks me for device name, I picked: `usb_switcher_3.2`

then at the end of all of this, a new file will be created called: `usb_switcher_3.2.lircd.conf`

Since in the instructions I ended up creating a device called `usb_switcher_3.2.lircd.conf`, I manaully copy the contents of `usb_switcher_3.2.lircd.conf`
and paste it at the end of `combined.lircd.conf.txt` which is a list of all the remotes I configured.

Afterwards, you can copy and paste and override the remote defined for the controller:  
`sudo cp ./combined.lircd.conf.txt /etc/lirc/lircd.conf`
and then confirm with 
`cat /etc/lirc/lircd.conf`
